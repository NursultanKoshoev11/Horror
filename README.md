I developed a horror game, creating an atmosphere of fear and tension using sound, lighting, and game design. During development, I used Unreal Engine, working on interaction mechanics, an AI system for enemies, and a dynamic environment.

Main features of the game:

Atmospheric horror – carefully designed lighting and sound enhance the sense of anxiety.

Interactive environment – the player can interact with objects, solve puzzles, and find a way out of eerie locations.

Advanced enemy AI – enemies react to sounds, light, and player behavior, creating a unique gameplay experience.

Story with psychological thriller elements – the narrative unfolds through the environment, notes, and mysterious events.

I carefully optimized the game to ensure stable performance and implemented a system of dynamic events that make each playthrough unique. In the future, I plan to add new mechanics, improve graphics, and expand the storyline.
